## 💡 使用提示

### 如何查看新布局？
1. 启动应用（`npm run dev`）
2. 点击侧边栏"布局"标签
3. 使用分类Tab切换不同类型的布局
4. 点击布局卡片即可选择

### 布局ID命名规则
- `grid-*` - 基础网格布局
- `creative-*` - 创意组合布局
- `social-*` - 社交媒体布局

### 如何添加新布局？
编辑 `src/core/models/LayoutConfig.ts`，在 `LAYOUT_TEMPLATES` 数组中添加新的布局对象：
```typescript
{
  id: 'your-layout-id',
  name: '布局名称',
  category: LayoutCategory.Grid, // 或 Creative、Social
  cells: [[x, y, w, h], ...],    // 归一化坐标
  imageCount: 4,                   // 图片数量
  tags: ['标签1', '标签2']
}
```
