## 🔧 技术实现要点

### 数据抓取技术栈

```javascript
// 核心抓取逻辑
const layoutItems = Array.from(document.querySelectorAll('ul li'));

for (let i = 0; i < layoutItems.length; i++) {
  item.click();                              // 点击布局
  await new Promise(r => setTimeout(r, 100));  // 等待更新
  const gridClasses = Array.from(item.classList); // 提取类名
  
  layouts.push({
    index: i + 1,
    gridCols: extractGridCols(gridClasses),  // 解析列数
    isActive: item.classList.contains('active')
  });
}
```

### 数据提取方法

1. **DOM类名解析**
   - 从 `grid-cols-{n}` 类名提取列数
   - 示例: `grid-cols-2` → 2列布局

2. **占位符计数**
   - 尝试统计画布上的 "+" 占位符
   - 受限于DOM结构，未能直接获取

3. **视觉验证**
