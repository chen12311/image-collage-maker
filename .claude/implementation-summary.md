- 精度: 保留3位小数
- 特殊比例:

## 🔧 技术实现要点

### 特殊布局处理

#### 1. 重叠布局（层叠叠加）
```typescript
cells: [
  [0, 0, 0.6, 0.5],
  [0.3, 0.25, 0.6, 0.5],  // 与上一个重叠
  [0.1, 0.5, 0.6, 0.5]    // 继续重叠
]
```

#### 2. 错位布局（阶梯式）
```typescript
cells: [
  [0, 0, 0.33, 0.5],
  [0.33, 0.25, 0.34, 0.5],  // 垂直偏移0.25
  [0.67, 0.5, 0.33, 0.5]    // 垂直偏移0.5
]
```

#### 3. 比例布局（黄金分割）
```typescript
cells: [
  [0, 0, 0.618, 0.5],      // 黄金比例宽度
  [0.618, 0, 0.382, 0.5],  // 补充宽度
  [0, 0.5, 0.382, 0.5],
  [0.382, 0.5, 0.618, 0.5]
]
```
