# 问题分析：2*2 布局下图片控件显示异常

## 问题描述

用户报告：当选择 2*2 布局时，图片上的功能（控制按钮）只在第一张图片上显示。

## Playwright 测试结果

### 测试环境
- 日期：2025-10-14
- 布局：2*2（4张图片）
- 测试图片：4张彩色测试图片

### 关键发现

通过 Playwright 自动化测试，我发现了以下问题：

**✅ 正常部分：**
1. 布局系统工作正常，正确创建了 4 个单元格
2. 交互层正确创建了 4 个热区（interaction-zone）
3. 图片正确显示在 4 个位置
4. 单元格位置计算正确（LayoutEngine.ts）

**❌ 异常部分：**
1. 当鼠标从第一张图片移动到第二张图片时，**同时出现 2 个控件**
2. 第一张图片的控件没有及时消失（Transition 动画问题）

### 测试数据

悬停第一张图片：
- 控件数量：1
- 控件位置：`left: 391px, top: 4px`（正确）

悬停第二张图片：
- 控件数量：2（**异常！应该只有1个**）
- 控件位置：
  - 控件 1：`left: 391px, top: 4px`（第一张图片位置，应该消失）
  - 控件 2：`left: 796px, top: 4px`（第二张图片位置，正确）

## 根本原因分析

### 问题 1：架构设计缺陷

当前实现在 `CanvasInteractionLayer.vue` 中的架构：

```vue
<template>
  <div class="interaction-layer">
    <!-- 为每个单元格创建一个热区 + 控件 -->
    <div v-for="(cell, index) in computedCells" :key="...">
      <Transition name="controls-fade">
        <ImageControls
          v-if="hoveredIndex === index && images[index]"
          ...
        />
      </Transition>
    </div>
  </div>
</template>
```

**问题：**
- 每个热区内部都有独立的 `<Transition>` 和 `<ImageControls>` 组件
- 当 hoveredIndex 改变时，旧的控件开始淡出，新的控件开始淡入
- **在动画过渡期间，两个控件同时存在**

### 问题 2：key 值不稳定

```vue
:key="images[index]?.id || `cell-${index}`"
```

- 当没有图片时，key 是 `cell-0`, `cell-1`...
- 当有图片时，key 是图片的 id
- key 的切换可能导致 Vue 无法正确追踪组件实例

### 问题 3：Transition 动画时序

```vue
.controls-fade-enter-active,
.controls-fade-leave-active {
  transition: opacity var(--duration-fast) var(--ease-in-out);
}
```

Transition 的进入和离开动画是异步的，导致多个控件实例在短时间内共存。

## 解决方案

### ✅ 推荐方案：全局单一控件（架构重构）

**原理：**
不在每个热区内创建控件，而是在交互层只创建一个全局控件，根据 hoveredIndex 动态调整位置。

**优势：**
1. ✅ 只有一个控件实例，彻底避免多实例问题
2. ✅ Transition 动画更流畅（只有一个元素在过渡）
3. ✅ 性能更好（减少 DOM 节点数量）
4. ✅ 逻辑更清晰，易于维护
5. ✅ 避免 key 值不稳定问题

**实现代码：**

```vue
<template>
  <div class="interaction-layer" ref="layerRef" :style="layerStyle">
    <!-- 交互热区（只负责鼠标事件，不包含控件） -->
    <div
      v-for="(cell, index) in computedCells"
      :key="`zone-${index}`"
      class="interaction-zone"
      :style="getZoneStyle(cell)"
      @mouseenter="handleMouseEnter(index)"
      @mouseleave="handleMouseLeave(index)"
    />
    
    <!-- 全局控件（只有一个实例，根据 hoveredIndex 动态定位） -->
    <Transition name="controls-fade">
      <ImageControls
        v-if="hoveredIndex !== null && images[hoveredIndex] && computedCells[hoveredIndex]"
        :key="`controls-${hoveredIndex}`"
        :x="computedCells[hoveredIndex].x"
        :y="computedCells[hoveredIndex].y"
        :width="computedCells[hoveredIndex].width"
        :height="computedCells[hoveredIndex].height"
        @flip-horizontal="handleFlipHorizontal(images[hoveredIndex].id)"
        @flip-vertical="handleFlipVertical(images[hoveredIndex].id)"
        @rotate="handleRotate(images[hoveredIndex].id)"
        @delete="handleDelete(images[hoveredIndex].id)"
      />
    </Transition>
  </div>
</template>
```

**关键改变：**
1. 将热区和控件分离
2. 只创建一个全局的 ImageControls 组件
3. 使用稳定的 key 值：`key="`controls-${hoveredIndex}`"`
4. 控件位置由当前 hoveredIndex 对应的 cell 决定

### 备选方案 1：移除 Transition 动画

如果不需要淡入淡出动画，可以直接移除 Transition：

```vue
<ImageControls
  v-if="hoveredIndex === index && images[index]"
  ...
/>
```

**优点：** 简单快速
**缺点：** 失去了视觉过渡效果

### 备选方案 2：修复 key 值

使用稳定的 key 值：

```vue
:key="`cell-${index}`"
```

**优点：** 改动小
**缺点：** 不解决多实例共存的根本问题
